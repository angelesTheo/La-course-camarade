# Cours, camarade

Un runner de rue en trois voies, en HTML et JavaScript, sans dépendance. Une bande d'étudiants court de nuit en évitant les policiers, les gendarmes, les CRS, l'armée et Big M, entre poubelles, grillages, feux, palettes, voitures en feu, abris bus et nuages de gaz lacrymogène.

## Jouer

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur la branche `main`.

## Commandes

- ↑ ou Z : voie du haut
- ↓ ou S : voie du bas
- Espace : sauter
- P : pause
- Mobile : glisser vers le haut ou le bas pour changer de voie, toucher pour sauter

## Règles

- Saute les poubelles, les grillages, les feux et les barricades de palettes.
- Change de voie pour contourner les abris bus, les voitures en feu et les poursuivants.
- Un nuage de gaz lacrymogène bloque deux voies à la fois. Les CRS avancent parfois en cordon sur deux voies.
- Trois camarades au départ. Un café ou un street medic en ramène un.
- Le record est gardé dans le navigateur (`localStorage`).

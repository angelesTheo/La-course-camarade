# Cours, camarade

Un runner de rue en trois voies, en HTML et JavaScript, sans dépendance. Une bande d'étudiants court de nuit en évitant les policiers, les gendarmes, l'armée et Big M, entre poubelles, grillages, feux et abris bus.

## Jouer

Ouvrir `index.html` dans un navigateur, ou activer GitHub Pages sur la branche `main`.

## Commandes

- ↑ ou Z : voie du haut
- ↓ ou S : voie du bas
- Espace : sauter
- P : pause
- Mobile : glisser vers le haut ou le bas pour changer de voie, toucher pour sauter

## Règles

- Saute les poubelles, les grillages et les feux.
- Change de voie pour contourner les abris bus et les poursuivants.
- Trois camarades au départ. Un café en ramène un.
- Le record est gardé dans le navigateur (`localStorage`).
